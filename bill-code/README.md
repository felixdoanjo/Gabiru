## Sobre

Gabiru é um **Workspace Brasileiro e Open Source** que coloca várias funcionalidades úteis em um só lugar com auxílio da IA. O objetivo é rodar na sua máquina **localmente**, te dando acesso a diversas opções que você precisaria buscar em apps diferentes, mas em um único lugar.

### Características Principais

- **100% Gratuito** - Sem custos, sem taxas escondidas
- **Open Source** - Código aberto para a comunidade
- **Local First** - Roda tudo na sua máquina, privacidade garantida
- **IA Integrada** - Assistentes de IA em todas as funcionalidades
- **Feito no Brasil** - Desenvolvido com ❤️ por brasileiro

### 11. Navegador Integrado

Um navegador integrado no próprio app. A IA já recebe as informações do site que você acessou, sempre pronta para ajudar no que for preciso. É possível dividir abas, fixar elas e muito mais.

## Download

### Requisitos
- Windows 10/11 (64-bit)
- ~200MB de espaço livre
- Conexão com internet (para instalação de dependências)

### Instalação

1. Baixe o instalador: **[Gabiru Setup 1.0.0.exe](https://github.com)** (em breve)
2. Execute o instalador
3. Siga as instruções na tela
4. O app instalará automaticamente as dependências necessárias (Python, FFmpeg, etc.)
5. Pronto! O Gabiru está instalado e pronto para usar

## Tecnologias

- **Electron** - Framework desktop
- **React** - Interface do usuário
- **TypeScript** - Linguagem principal
- **Python** - Backend para processamento de IA
- **FFmpeg** - Processamento de mídia
- **Piper TTS** - Text-to-Speech
- **Whisper** - Transcrição de áudio
- **OpenCV** - Processamento de imagens

## Sobre o Projeto


Eu sou o responsável pelo Gabiru. Trabalhei sozinho no meu tempo livre desenvolvendo um ambiente que fosse gratuito e que pudesse entregar mais de uma coisa de uma vez.

**Nenhum único centavo foi gasto** no desenvolvimento desse aplicativo, tudo foi feito de forma gratuita, apenas meu tempo foi investido.

O Gabiru ainda está em fase beta, e ele não é o que eu quero que ele seja, mas nem de perto, porém eu gostei do resultado e foi divertido fazê-lo. Espero que vocês também tenham gostado!

Cada crítica, solução de bug e pedidos serão de extrema importância para mim, e pretendo não abandonar o projeto. Vou atualizá-lo eventualmente na medida do possível.
